## 4. Animation notes for the editor

The animation is built in code (same engine as R05). Changes go into the scene files, not a timeline.

- **Files:** `index.html` (grid background, BUILDPEDIA tag, captions, scene cross-fades, scene list `s1`–`s8`), `lib.js` (palette `P`, helpers `L`, identical to R05), `scenes/s1.js` to `s8.js` (one scene each; `s1.js` also defines the shared `R20A` helpers: cube, strength bar, hard hat, drop, pill, bracket), `timing.json` (master clock), `render.mjs`, `build.sh`.
- **Timing source of truth is `timing.json`.** Every hit is placed with `L.wordTime(T, 'L0x', 'word')` (or `R20A.wt` for the n-th repeat of a word). If the VO is ever re-voiced, regenerate `timing.json` and the visuals follow. Never retime by hand.
- **Deterministic:** all randomness uses `L.rng(seed)`; no `Math.random`/`Date`. Every render is identical.
- **Captions:** the spoken "M twenty." is shown as one caption token **"M20."** (merge in `index.html`, `CAPL`). Everything else is word for word.
- **Transitions:** 0.28 s cross-fade between scenes (`FADE`).
- **Key sync points:** USE / M / 20 at 1.66 / 1.94 / 2.09 s · "?" 2.55 · split on "mean?" 4.15 · MIX 5.66 · STRENGTH GRADE 7.06–7.60 · cubes 9.70 · press closes 11.17 · needle at DESIGNED 14.00 · arrow 15.60 · STRONGER 16.98 · coins 18.06–19.13 · callouts 21.68 / 21.96 / 22.67 · ingredients 28.28 / 28.75 / 29.08 / 30.00 · scale level 31.30 · pour 32.54 · WEAKER 34.69 · ticks 37.66 / 40.01 · plane 40.85.
- **Palette (same as R05):** navy `#0E2A47`, chalk `#EAF2FF`, water `#4FC3F7`, orange accent `#FF8A3D`, strength green `#7CE0A3`; Inter 800. Scene art stays inside x 60–1020, y 230–1340.
- **Numbers:** the only digits on screen are "20" in "M20" (bubble, split letters, caption). The gauge, strength bar, ladder and coins carry no figures.

- Tempo ≈ 88.7 BPM (R05 86.5) so that bar 9, the "lift" (flowing 8ths, soft kick + shaker, brighter pad), lands at 24.36 s, in the breath right before "But on site". The final rolled Dmaj9 lands at 43.31 s after "building." and fades out by 44.41 s.
