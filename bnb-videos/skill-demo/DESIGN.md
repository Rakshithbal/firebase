# BNB editorial design system — R05 v2 (house template)

The look: a NYT / Bloomberg / Vox graphics explainer drawn on a BNB blueprint. Calm type, precise
linework, one idea per scene, one orange thing per scene. **Golden reference: `compositions/s1.html`.**
Follow this file exactly; when it is silent, copy what s1 does.

Shared files (owned by the art director — scene agents must NOT edit them):
`index.html`, `assets/bnb.css`, `assets/bnb.js`, `assets/timing.js`, `compositions/bg.html`,
`compositions/chrome.html`, `compositions/captions.html` (generated by `tools/gen.py`), this file.
A scene agent edits only its own `compositions/sN.html`.

## 4. Illustration

- **Three line weights**: hairline 1.5 (hatch, extension lines, coursing, rules), standard 3 (secondary outlines, leaders, dims at 2), heavy 5 (primary section outline, slab surface). `BNB.LW`.
- **Section conventions**: everything is a vertical section (cut) or an elevation, drawn front-on. No perspective, no isometric (exception: none in this film). Cut materials: concrete = flat grey + seeded aggregate polygons + sand specks; masonry = terracotta wash + hairline coursing; ground = heavy line + 45° earth ticks; steel = navy core, chalk ring, small highlight; water = flat `--water` (film at 55%), or drops.
- **Hatching** (`BNB.hatch`): shade = 45° hairline at 8 px, chalk 16%; heat = 45° at 7 px; strength fill = -45° navy hatch over green. Shading is always hatch, never a gradient.
- **Dimension lines** (`BNB.dim`): 2 px `--blue`, hairline extension lines 14 px past the dim line, 45° architectural ticks, mono label on a ground-coloured knock-out. Labels are words (SPAN, DEPTH) — never numbers.
- **Leader callouts** (`BNB.callout`): dot terminal r 6.5 with an 11 px ground halo on the subject, 2 px straight leader to a shoulder rule, mono head (UPPER) above Inter body. Text never sits on the drawing; leaders never cross text.
- **Draw deterministically in inline SVG**, built once at init by the `BNB.*` builders (seeded `BNB.rng`, no `Math.random`), animated only by the scene's GSAP timeline (dash draw-on, opacity, transforms, `attr` fills). Canvas is allowed only via the `hf-seek` protocol (`renderAt(e.detail.time)`), but don't: SVG is the house method. Never `getBBox()` at init (hosts can be hidden).

## 5. Motion

Easing tokens (`BNB.E`) — the only eases allowed:
`enter` power3.out (type + objects arriving) · `land` expo.out (hero landings, rules, camera settle) ·
`move` power2.inOut (camera, colour/state change) · `draw` power2.inOut (draw-on) · `exit` power2.in ·
`drift` sine.inOut (camera drift) · `linear` none (rotation, progress only).
**Banned:** back.*, elastic.*, bounce, any overshoot pop, breathing/pulsing loops, `repeat: -1`, slide-up-and-fade on everything.

Durations (`BNB.D`): ticks/dots 0.25 · type 0.5 · objects/callouts 0.7 · draw-on 0.9 · exits 0.2–0.3 (40–50% of the entrance).
Staggers (`BNB.STAGGER`): words 0.06 · list items 0.08 · hatch strokes 0.012.

- Type enters by blur 8→0 + opacity (no translate), or kicker wipe (`BNB.a.kicker`). A landed title is dead still.
- Lines draw on (`BNB.a.draw`). Callouts: dot → leader → rule → text (`BNB.a.callout`).
- Land visuals on the spoken word: `var at = BNB.sceneAt(sceneStart, "L0x"); at("word")` gives scene-local seconds. Land a beat 0–0.1 s after the word starts; anticipation (a draw starting) may begin up to 0.25 s before.
- One emphatic moment per scene max, and it is a *state change* (strike, fill, colour), not a slam. **The NOT YET stamp in s1 is the film's only slam + shake.** Nobody else shakes the camera.
- Camera: each scene has `#sN-cam` with `BNB.a.drift` (≈12–16 px vertical over the scene, sine.inOut). Optional `#sN-zoom` settle 1.045→1 expo.out at the start. No creeping push late in a scene.
- Transitions, each with a cause: (a) **match cut on the slab** (canonical geometry, preferred between slab scenes), (b) **object becomes the world** (zoom through a detail: s2→s3 lens), (c) **blur swap on one stage** `BNB.a.exit` (default; the grid behind never cuts). Each scene owns its exit in its final 0.22–0.3 s and starts its entrance at 0. The grid nudges at every seam (bg.html).
- Frame 0 of the film (s1) is the thumbnail: header + figure already on the page.

## 6. Helper library API (`assets/bnb.js` → `window.BNB`)

Tokens: `BNB.C` (colours), `BNB.LW`, `BNB.E`, `BNB.D`, `BNB.STAGGER`, `BNB.STAGE`, `BNB.SCENES[i] = {id,start,dur,line,kicker}`.
Timing: `BNB.at(line, word, n?)` (film s) · `BNB.sceneAt(sceneStart, line)` → `at(word, n?)` (scene s) · `BNB.rng(seed)`.
SVG primitives: `BNB.el(tag, attrs, parent)` · `BNB.g(parent, attrs)` · `BNB.path(parent, d, attrs)` · `BNB.line(parent,x1,y1,x2,y2,attrs)` · `BNB.text(parent,x,y,str,cls,attrs)` · `BNB.defs(svg)` · `BNB.hatch(svg,{id,angle,gap,color,width,bg})` → `"url(#<svgId>-id)"` (pattern ids are prefixed with the owning svg's id so each scene has its own copy — always use the returned url). `BNB.text(…,{fill})` writes the fill inline so it beats the `.t-*` class colour.

Builders (return element refs to animate):

A new reusable drawing (hessian sack, spray nozzle, clipboard, lens, cement grain…) is built **inside the scene file** as a local function first; if a second scene needs it, ask the art director to promote it into `bnb.js`.

## 7. Captions

Generated, never hand-edited: `python3 tools/gen.py` writes `assets/timing.js` and `compositions/captions.html`.
Sentence-level lines (break at `.?!`, at a comma after ≥4 words, max 13 words), centred, 880 px wide,
balanced wrap, y 1396. The whole line blurs in (0.22 s) as speech starts; each word turns from muted
blueprint `#7d93ae` to chalk as it is spoken (0.14 s). No pills, no highlight boxes, no orange.

## 8. Texture

`bg.html`: flat navy, blueprint grid (24/96 px at 2.6%/5.5%), soft lift behind the figure, vignette to ink;
constant drift + small parallax nudge at each seam. `chrome.html`: fractal-noise grain at 7%, soft-light,
re-positioned every 2 frames from a hash of the frame step (seek-safe). Scenes add no texture of their own.

```html
  <div id="root" data-composition-id="sN" data-duration="<slot>">
    <style> #root{position:absolute;inset:0;overflow:hidden;color:#eef3fa}
            #sN-cam,#sN-zoom{position:absolute;inset:0}  /* + scene-local rules, all ids prefixed sN- */ </style>
    <div id="sN-cam" class="bnb-stage"><div id="sN-zoom" class="bnb-stage">
      <svg id="sN-fig" class="bnb-fig" viewBox="0 0 1080 1920"><defs></defs></svg>
      <header class="bnb-head"><div class="bnb-kicker" id="sN-kicker"><b>0N</b> — Title</div>
        <h1 class="bnb-headline" id="sN-hl">Sentence case claim</h1><p class="bnb-deck" id="sN-deck">…</p></header>
      <div class="bnb-figcap" id="sN-figcap" style="top:1218px"><div class="rule"></div>
        <div class="txt"><span class="num">Fig. N</span><span class="sep">·</span><span class="desc">…</span></div></div>
    </div></div>
    <script>(function(){
      var B=BNB, C=B.C, E=B.E, SC=B.SCENES[N-1], at=B.sceneAt(SC.start,"L0x");
      var svg=document.getElementById("sN-fig"), fig=B.g(svg,{id:"sN-figure"});
      /* 1. build geometry with B.* (ids prefixed sN-) */
      var tl=gsap.timeline({paused:true});
      B.a.drift(tl,"#sN-cam",SC.dur);
      /* 2. entrance from t=0 (match the previous scene's exit), 3. beats on at("word"), 4. exit: */
      B.a.exit(tl,"#sN-cam",SC.dur-0.22,0.2);
      window.__timelines["sN"]=tl;
    })();</script>
  </div>
</template>
```

- `data-duration` = the slot in `index.html` / `BNB.SCENES` (s2 4.43 · s3 6.103 · s4 10.026 · s5 7.334 · s6 9.91 · s7 3.296). Times in the scene are scene-local.
- Use `fromTo` (or `immediateRender:false` on later tweens of the same property). No `from`. No CSS transform on anything GSAP transforms.
- Every id prefixed `sN-`; pattern/clip ids passed to builders must be unique per scene (`BNB.slab(svg, fig, {id:"sN-slab"})`).
- Done = `npm run check` with 0 errors (the `outside_safe_zone` TikTok/Shorts warnings and `text_below_floor` for 24 px mono labels are accepted), plus `npx hyperframes snapshot --at …` frames you have looked at.

## 10. Content rules (hard)

No number of days, no percentages, no MPa, no quantities or figures of any kind. The only digits allowed on
screen are editorial indices: kicker `0N` and `Fig. N`. Strength is shown as a bar with no scale.
No logos (the mono word BUYNBUILD in the sign-off mark is type, not a logo). No faces, no people, no hands.
No AI imagery, no photos, no stock icons — everything is drawn in the system above.
